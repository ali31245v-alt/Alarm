# Smart Alarm — المنبّه الذكي

تطبيق منبّه عربي بواجهة داكنة ولمسات بنفسجية.

## المزايا
- إضافة منبّهات وتحديد الوقت والاسم.
- اختيار أيام التكرار.
- تفعيل المنبّه أو إيقافه وحذفه.
- حفظ المنبّهات على الجهاز.
- إشعارات محلية وبناء APK تلقائي عبر GitHub Actions.

## تنزيل APK
افتح تبويب **Actions**، اختر آخر تشغيل ناجح لـ **Build Smart Alarm APK**، ثم نزّل **smart-alarm-apk** من قسم Artifacts.

ملاحظة: تأكد من السماح بالإشعارات للتطبيق، وقد تؤثر إعدادات توفير البطارية في توقيت التنبيه.
